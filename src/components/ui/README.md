# Arenile mobile UI kit (React Native Reusables)

[React Native Reusables](https://reactnativereusables.com) (shadcn/ui for React Native, on
[NativeWind](https://www.nativewind.dev) v4 and `@rn-primitives`) is **the** component system of the
app, mirroring shadcn/ui in the core panel (core ADR 0009, here ADR 0004). Components live here,
generated by the Reusables CLI from `components.json`, and are imported as `@/components/ui/<name>`.

**No custom styling.** Styling = Reusables variants + NativeWind utilities on theme tokens. No
`StyleSheet`, no `style={…}`, no stylesheet other than `src/global.css` (theme variables), no raw
colours, no default Tailwind palette (`bg-red-500`, `text-white`), no arbitrary values
(`text-[10px]`, `w-[2px]`); layout values such as `max-w-[32rem]` are fine. `npm run lint`
(`scripts/style-guard.js`) enforces this. The vendored files in this folder are exempt from the
palette/arbitrary-value checks because the CLI generates them (e.g. `shadow-black/5`, `h-[1px]`).

## Adding a component

```bash
npx @react-native-reusables/cli@latest add <name> --styling-library nativewind
npx prettier --write src/components/ui/<name>.tsx
```

The CLI installs the `@rn-primitives/*` package it needs. Check that the new dependency is pure
JavaScript (no native code, otherwise use `npx expo install`), then list any local change below.
Hard-coded English strings in generated code must go through `t('…')`.

Available: alert, alert-dialog, badge, button, card, icon, input, label, native-only-animated-view,
radio-group, separator, text.

## Local changes to generated components (keep them when re-adding)

- `button`, `badge`: the destructive variant uses `text-destructive-foreground` instead of
  `text-white` (the dark theme's destructive is a light red, white text would fail contrast);
  `button` destructive no longer dims to `dark:bg-destructive/60` for the same reason.

- `input`, `button`: 44 pt touch targets at every width (`.claude/rules/frontend.md`). The generated
  sizes shrink at `sm:` (640 dp, i.e. on every iPad) and start at 40 pt: `input` and the `default`
  and `icon` button sizes are `h-11`, `lg` is `h-12`, `sm` keeps `h-9` (callers add `min-h-11` when
  it is a touch target); no `sm:` heights.

## Theme

`src/global.css` holds the tokens as HSL triplets (so `bg-primary/90` works), converted from the core
panel theme (`web/shared/src/styles/globals.css` in the core, Coste360 navy/sky, core ADR 0018), with
the source hex next to each value. `tailwind.config.js` maps them; `src/lib/theme.ts` repeats the few
colours React Navigation needs (headers, screen backgrounds) and `src/lib/theme.test.ts` keeps both in
sync. The map status colours (`--status-*`) arrive with the map in Phase 1.
