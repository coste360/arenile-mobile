# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

@AGENTS.md

## Claude Code specifics

- Project skills live in `.claude/skills/` (`polishing-adaptive-layouts` for phone/tablet layout
  work).
- Path-scoped rules live in `.claude/rules/`; they load automatically when you touch matching files.
  Follow them as strictly as AGENTS.md.
- The Expo plugin (`expo@claude-plugins-official`) is enabled in `.claude/settings.json`: prefer its
  skills and the versioned Expo docs over memory.
- Before declaring a task complete, delegate a review to the `reviewer` subagent.
- Use `test-writer` to extend table-driven or screen tests instead of writing them inline when more
  than a few cases are needed.
- Formatting runs automatically after edits (hook `scripts/agents/format-file.sh`); do not run
  formatters manually.
- Edits to generated files (`src/api/generated/**`, `api/openapi.yaml`, `api/core-version.json`,
  `ios/`, `android/`) are blocked by the hook `scripts/agents/guard-generated.sh`. If it blocks you,
  use `make gen` / `make api-bump VERSION=…`, or configure native behaviour in `app.json`.
- `expo prebuild` and `eas update` are denied in `.claude/settings.json`: native projects are
  generated by EAS Build, and OTA updates are excluded by ADR 0005.
- Personal preferences go in `CLAUDE.local.md` (git-ignored), never in this file.
